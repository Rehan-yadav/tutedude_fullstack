# Promise-based Divide Function

## Objective
A JavaScript arrow function `divide(a, b)` that returns a Promise.

- If `b` is 0, the Promise is **rejected** with the message "Error: Division by zero is not allowed."
- Otherwise, the Promise is **resolved** with `a / b`.

## Files
- `index.html` – page structure
- `style.css` – styling
- `script.js` – divide function and 6 test cases

## How to run
Open `index.html` in a browser and check the page / browser console.

## Sample Output
Dividing 10 by 2...
Result: 5

Dividing 10 by 0...
Error: Division by zero is not allowed.
