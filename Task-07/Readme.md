# Laundry App – Responsive Hero Section (Task 3)

Responsive Navbar and Hero section for the laundry web app, built with plain HTML and CSS (no Bootstrap).

## Files
- `index.html` – page structure
- `style.css` – styles and media queries
- `images/washing-machine.png` – hero image

## Responsive behaviour
| Screen  | Breakpoint | Changes |
|---------|-----------|---------|
| Desktop | > 1024px  | Full navbar, text left / image right |
| Tablet  | ≤ 1024px  | Smaller logo, links, username, headline and image |
| Mobile  | ≤ 600px   | Nav links hidden, layout switches to `flex-direction: column` |

## How to run
Open `index.html` in a browser and use DevTools device toolbar to test tablet (iPad Mini, 768px) and mobile (375px).
