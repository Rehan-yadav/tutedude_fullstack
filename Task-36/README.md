JWT Authentication System
A full-stack JWT Authentication System built using React.js, Node.js and Express.js. This project allows users to register, log in, and access protected routes using JSON Web Tokens (JWT).

Features
User Registration
User Login
Password Hashing using bcryptjs
JWT Token Generation
JWT Token Verification
Protected Routes
Authentication Middleware
Logout Functionality
Form Validation
Error Handling
Responsive User Interface
