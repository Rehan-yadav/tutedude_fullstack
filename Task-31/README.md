Node.js Web Server
Project Description
This project is a simple web server built using Node.js and its built-in HTTP module. It handles different routes and serves HTML pages based on the URL requested by the user.
It also includes a custom 404 error page for invalid routes.

Technologies Used
Node.js
JavaScript
HTTP Module
HTML5
CSS3

Features
HTTP server using Node.js.
Handles GET requests.
Multiple routes (Home, About, Contact).
Custom 404 error page.
HTTP status codes (200, 404, 405, 500).
CSS styling.
Asynchronous file reading using the File System module.
