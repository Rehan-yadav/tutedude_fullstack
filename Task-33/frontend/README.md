– Frontend
 Project Overview
The frontend of Task-33 is developed using React.js.
It provides a user-friendly interface to manage daily tasks. Users can add new tasks, view tasks, edit existing tasks, delete tasks, mark tasks as completed, and search tasks.
The frontend communicates with the backend using Axios and RESTful APIs.

Technologies Used
React.js
JavaScript
HTML5
CSS3
Axios
Vite

 Features

1. Add Task
Create a new task.
Enter task title and description.

2. View Tasks
Display all available tasks.
Fetch data from the backend API.

3. Edit Task
Update existing task details.
4. Delete Task
Remove tasks from the list.

5. Complete Task
Mark tasks as completed or pending.

6. Search Task
Search tasks using their title.

7. User Feedback

Loading indicators.
Success messages.
Error messages.
Empty task list message.

API Integration
The frontend uses Axios to communicate with the backend.
