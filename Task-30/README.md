Offline Chess Game
An offline two-player chess game developed using React and JavaScript. Players can play chess locally on the same device without requiring an internet connection.

Features
Two-player local chess gameplay
Legal move validation
Check and checkmate detection
Castling
En passant
Pawn promotion
Move history
Undo move
Restart game
Chess timers
Captured pieces display
Draw detection
Game result display

Technologies Used
React.js
JavaScript
HTML
CSS
Vite
