# FreshCare Laundry Services - Hero Section

## Task

CSS - Laundry Services Hero Section

## Description

This project is a simple laundry service web application hero section created using HTML and CSS.

The main objective of this task is to design a clean and attractive hero section for a laundry service website.

## Features

- Navigation bar
- Logo on the left
- Home navigation link
- Services navigation link
- About Us navigation link
- Contact Us navigation link
- Username on the right
- Hero heading
- Laundry service description
- "Book a Service Today!" button
- Laundry-related image
- Responsive design

## Technologies Used

- HTML5
- CSS3

## CSS Concepts Used

The following CSS concepts were used in this project:

- Display property
- Inline-block
- Width and height
- Padding and margin
- Font styling
- Colors
- Border radius
- Hover effects
- Viewport units
- Media queries
- Vertical alignment

## Important Note

Flexbox has not been used for the navbar or hero section.

The layout is created using:

- `display: inline-block`
- Width
- Padding
- Margin
- Vertical alignment
- Viewport units

## Files

The project contains three files:

1. `index.html` - Contains the structure of the webpage.
2. `style.css` - Contains the styling of the webpage.
3. `README.md` - Contains information about the project.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The Laundry Services Hero Section will be displayed.
