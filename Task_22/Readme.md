 
# ✦ Project Workspace – Hero Landing Page

A modern, responsive hero landing page built using **HTML, Tailwind CSS, and JavaScript**. This project showcases a professional AI-powered workspace platform designed to help teams write, plan, manage projects, and collaborate efficiently.

## 🚀 Features

- **Sticky Navigation Bar** – Includes logo, navigation links, and a Get AI Free button.
- **Hero Section** – Attractive gradient background with a centered headline and description.
- **Call-to-Action Buttons** – Get AI Free and Request a Demo buttons.
- **Dashboard Preview** – A workspace dashboard displaying project statistics and recent tasks.
- **Floating Information Cards** – Three cards displaying:
  - Tasks completed today.
  - Project status (On Track).
  - Team activity (+5 online).
- **Fixed Chat Widget** – A floating chat button positioned at the bottom-right corner.
- **Responsive Design** – Adapts to different screen sizes using Tailwind CSS responsive utilities.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS (CDN)
- JavaScript
- VS Code

## ⚙️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure you have an internet connection (required for Tailwind CDN and external avatar images).
4. Open `index.html` in your browser.
5. Alternatively, use the **Live Server** extension in VS Code.

## 🎨 Tailwind CSS Concepts Implemented

This project demonstrates important Tailwind CSS utility classes:

| Utility | Purpose |
|---|---|
| `sticky` | Sticky navigation bar |
| `relative` | Creates positioning context |
| `absolute` | Positions floating cards |
| `fixed` | Fixed chat widget |
| `z-50` | Controls stacking order |
| `bg-gradient-to-b` | Gradient background |
| `shadow-xl` | Adds card shadows |
| `flex` | Flexible layouts |
| `items-center` | Vertical alignment |
| `justify-center` | Horizontal alignment |
| `sm:`, `md:`, `lg:` | Responsive breakpoints |

## 📱 Responsive Design

The landing page uses Tailwind CSS responsive utilities to provide a consistent experience across desktop, tablet, and mobile devices.
