
# OmniFood - Responsive Food Delivery Landing Page

## Project Overview

OmniFood is a responsive food delivery landing page developed using HTML5, CSS3 and JavaScript.

The project demonstrates a modern food delivery website with a clean layout, attractive images, pricing plans and responsive design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash Images

## Project Structure

omnifood-landing-page/

- index.html
- style.css
- script.js
- README.md

## Website Sections

1. Header and Hero Section
2. How It Works
3. Our Cities
4. Customer Testimonials
5. Pricing Plans
6. Footer

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html.
4. Right-click and select Open with Live Server.
5. The website will open in your browser.

An internet connection is required for external images and Google Fonts.

## Responsive Breakpoints

### Desktop
Above 900px:
- Full navigation bar.
- Four-column city grid.
- Three-column pricing cards.
- Two-column How It Works section.

### Tablet
651px to 900px:
- Two-column city grid.
- Reduced spacing.
- Responsive pricing layout.

### Mobile
650px and below:
- Single-column layout.
- Hamburger navigation.
- Stacked pricing cards.
- Responsive images and buttons.

### Small Mobile
380px and below:
- Smaller typography and spacing.
- Stacked hero buttons.
- Compact app store buttons.

## Features

- Responsive layout.
- CSS Grid and Flexbox.
- Mobile hamburger navigation.
- Smooth scrolling.
- Background image overlays.
