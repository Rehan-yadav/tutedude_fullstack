# 👟 Shoe Store

A simple online shoe shopping application built using React. Users can browse shoes, view prices, and manage their shopping cart.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Features
- Display shoe products
- Add products to cart
- Increase and decrease quantity
- Automatic total price calculation
- Home, Categories, and About Us sections
- Responsive user interface

## Installation

```bash
npm install
npm run dev
```

Open `http://localhost:5173/` in your browser.
