# JavaScript - Arrays and Functions

## Project Overview
Is project me JavaScript functions banaye gaye hain jo ek array ko argument ki tarah lete hain aur us par alag-alag operations karte hain. User screen par numbers enter karta hai aur result bhi screen par dikhta hai (console me bhi print hota hai).

## Objective
Aise JavaScript functions banana jo array receive karein aur ye kaam karein:

- Array me se **maximum number** find karna
- Array ke **saare elements ka sum** calculate karna
- Array me **odd numbers ki count** nikalna

## Features
- User input screen se liya jata hai (comma separated numbers)
- Output page par dikhta hai aur `console.log` me bhi print hota hai
- Alag-alag types ke functions use kiye gaye hain:
  - `findMax` - normal function (function declaration)
  - `calculateSum` - arrow function
  - `countOdd` - anonymous function (function expression)
- Empty ya invalid input ke liye error message

## Project Structure
```
project-folder/
│── index.html    # Page ka structure (input box, button, output area)
│── style.css     # Styling
│── script.js     # Functions aur logic
│── README.md     # Project ki information
```

## How to Run
1. Saari files ek hi folder me rakho.
2. `index.html` ko kisi bhi browser me open karo.
3. Input box me numbers likho, jaise: `4, 8, 2, 11, 6, 7, 10`
4. **Calculate** button par click karo.
5. Result screen par dikhega. Console dekhne ke liye `F12` dabao aur Console tab kholo.

## Sample Input and Output

**Input:**
```
4, 8, 2, 11, 6, 7, 10
```

**Output:**
```
Maximum number: 11
Sum of all elements: 48
Count of odd numbers: 2
```
