# Laundry Mart - Login Page

A responsive login page for Laundry Mart built with **HTML and CSS only**
(no Bootstrap). The layout is a split screen created with **Flexbox**.

## Features
- Split layout: illustration on the left, login form on the right
- Content centred using Flexbox (no margin/padding tricks)
- Container height set to 100vh
- Email and password inputs with placeholders
- Styled "Login" button with hover effect
- Responsive design for smaller screens

## Files
- `index.html` - page structure
- `index.css` - styling
- `washing-machine.png` - left-side illustration
- `Readme.md` - project documentation

## How to Run
1. Download or clone the folder.
2. Open `index.html` in any web browser.

## Technologies Used
- HTML5
- CSS3 (Flexbox)
