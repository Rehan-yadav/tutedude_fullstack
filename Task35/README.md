Workout Buddy – MERN Stack Application
About the Project
Workout Buddy is a full-stack workout tracking application built using the MERN stack (MongoDB, Express.js, React.js, and Node.js).
The application allows users to add workout records, view their saved workouts, and delete workouts. Workout data is stored in MongoDB and displayed dynamically on the React frontend.

Features
Add new workouts.
Display all saved workouts.
Delete existing workouts.
Store workout information in MongoDB.
Manage global state using React Context API.
Handle state updates using useReducer.
Responsive user interface.
REST API integration using Axios.
