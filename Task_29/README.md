A React-based online shoe shopping application that allows users to browse shoes, add products to their shopping cart, and complete a demo checkout using Context API.

Features
Display shoe products.
Add products to the shopping cart.
Increase and decrease product quantity.
Remove products from the cart.
Automatically calculate total price.
Navigate to the payment page.
Credit Card payment form.
Cash on Delivery option.
Display cart items on the payment page.
Order summary with total amount.
Payment success message.

Technologies Used
React.js
JavaScript
CSS
React Router DOM
Context API
Vite
