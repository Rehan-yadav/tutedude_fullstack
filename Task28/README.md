React Routing Blog App
A responsive blog-style web application built using React and React Router DOM. It demonstrates navigation between multiple pages without reloading the website.

Features
Home page with blog posts.
Dashboard page with blog statistics and recent posts.
Login page with a login form.
Signup page with a registration form.
Navigation between pages using React Router DOM.

Responsive layout.
Sidebar with profile information and popular posts.

Technologies Used
React.js
JavaScript
React Router DOM
HTML5
CSS3
Vite
